01 — ABOUT

Small systems.
Practical demonstrations.

I’m a Games Development graduate with a programming focus, interested in how interactive systems behave and how they can be built into larger game experiences.

This portfolio brings together individual functions and prototypes made with Unity and Unreal Engine. Some are focused technical tests, while others explore how interactive environments can communicate information to a player.

These projects are presented as evidence of work I have explored so far—not as claims that each is a finished commercial game. The next step is to expand the strongest examples with code excerpts, technical breakdowns, and clearer documentation of my individual contribution.
